# Security policy

## Status

This project is an unaudited learning project in its planning stage. Do not use
it to protect anything you cannot afford to lose or have exposed.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: on this repository, go to the
**Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what an attacker could do with
it. You will get a reply as soon as the maintainer is able to look at it; this
is a personal project with no guaranteed response time.

## Scope

The design is described in [docs/security.md](docs/security.md), including what
it does and does not try to defend against.
